# UI-тесты портала «Транспорт Севера»

Учебный проект по автоматизации функциональных UI-сценариев с использованием Playwright и паттерна Page Object.

## Технологии

- TypeScript
- Playwright
- Page Object Model

## Реализованные сценарии

1. Открытие гида и проверка основных элементов.
2. Листание слайдов и проверка счетчика.
3. Переход в FAQ по кнопке «Подробнее».
4. Навигация по вопросам FAQ.
5. Закрытие панели гида.

## Структура проекта

```text
tests/
├── pages/
│   ├── BasePage.ts
│   └── GuidePage.ts
└── tests/
    └── guide.test.ts
```

`GuidePage` содержит локаторы, пользовательские действия и состояние страницы.

В тестах выполняются функциональные сценарии и проверки ожидаемого состояния интерфейса.

## Установка

```bash

```
