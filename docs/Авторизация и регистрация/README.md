# Требования и преднастройки: Авторизация и регистрация

**Назначение раздела и сущности**
Раздел «Авторизация и регистрация» предназначен для:
- создания учетной записи пользователя;
- входа в портал;
- управления сохранением пользовательской сессии;
- авторизации через внешние сервисы;
- выхода из системы.
Основной сущностью является учетная запись пользователя, содержащая:
- имя;
- фамилию;
- почту;
- пароль.

**Форма регистрации**
- Форма регистрации содержит поля:
  - «Имя»;
  - «Фамилия»;
  - «Почта»;
  - «Пароль»;
  - «Повторите пароль».
- Для регистрации **обязательны все 5 полей**.
- На форме доступна кнопка «Зарегистрироваться».
- На форме регистрации доступны кнопки:
  - «Войти через VK»;
  - «Войти через Яндекс».
- Подтверждение регистрации через Email-ссылку или SMS-код **не требуется**.

**Валидация регистрации**
- Поля «Имя» и «Фамилия»:
  - принимают значения на кириллице или латинице;
  - должны содержать **не менее 2 символов**.
- Поле «Почта» должно содержать корректный Email.
- Поле «Пароль»:
  - должно содержать **не менее 5 символов**;
  - не имеет дополнительных ограничений по используемым символам.
- Значения полей «Пароль» и «Повторите пароль» должны полностью совпадать.
- Валидация выполняется:
  - при вводе данных;
  - после потери фокуса полем.
- Невалидное поле визуально выделяется **красной рамкой**.
- При наличии хотя бы одного невалидного обязательного поля **регистрация не выполняется**.

**Успешная регистрация**
- После успешного создания учетной записи:
  - отображается **зеленое уведомление «Вы успешно зарегистрированы!»**;
  - открывается форма входа с URL /#/login.
- На форме входа автоматически заполняются:
  - поле «Почта» значением, указанным при регистрации;
  - поле «Пароль» значением, указанным при регистрации.
- Новый пользователь может войти в систему сразу после регистрации без дополнительного подтверждения учетной записи.

**Уникальность Email**
- Один Email не может использоваться несколькими учетными записями.
- При попытке регистрации с Email существующего пользователя:
  - новая учетная запись **не создается**;
  - форма регистрации остается открытой;
  - отображается уведомление об ошибке регистрации.

**Форма авторизации**
- Для входа используются поля:
  - «Почта»;
  - «Пароль».
- В качестве логина используется Email зарегистрированного пользователя.
- На форме доступен чекбокс **«Оставаться в системе»**.
- На форме доступны кнопки:
  - «Войти через VK»;
  - «Войти через Яндекс».
- Функция восстановления пароля в интерфейсе отсутствует.

**Ошибки авторизации**
- При неверном пароле или использовании незарегистрированного Email:
  - вход **не выполняется**;
  - форма авторизации остается открытой;
  - отображается красное уведомление о неверных учетных данных.
- Повторные неверные попытки входа:
  - не приводят к блокировке учетной записи;
  - не вызывают появление капчи;
  - не блокируют последующую авторизацию с корректными учетными данными.

**Успешная авторизация**
- При вводе корректного Email и пароля пользователь авторизуется в системе.
- После успешного входа:
  - отображается **зеленое уведомление «Вход выполнен»**;
  - форма авторизации закрывается;
  - открывается боковое меню.
- В боковом меню отображаются:
  - иконка профиля;
  - имя и фамилия пользователя;
  - кнопка **«Выход»**.
- Кнопка «Вход» для авторизованного пользователя не отображается.

**Сохранение сессии**
- Если при авторизации включен чекбокс **«Оставаться в системе»**:
  - пользовательская сессия сохраняется после полного закрытия браузера;
  - после повторного запуска браузера пользователь остается авторизованным.
- Если чекбокс «Оставаться в системе» не включен:
  - после завершения браузерной сессии пользователь становится неавторизованным;
  - для продолжения работы требуется повторный вход.

**Авторизация через внешние сервисы**
- Авторизация поддерживается через:
  - VK ID;
  - Yandex ID.
- Нажатие соответствующей кнопки:
  - открывает окно авторизации выбранного внешнего сервиса;
  - позволяет выполнить вход под учетной записью внешнего провайдера.
- После успешного подтверждения авторизации:
  - пользователь возвращается в портал «Транспорт Севера»;
  - создается авторизованная сессия;
  - в меню отображаются данные профиля внешнего сервиса;
  - отображается кнопка «Выход».

**Выход из системы**
- Выход выполняется по кнопке **«Выход»** в боковом меню.
- После выхода:
  - пользовательская сессия прекращается;
  - данные профиля скрываются;
  - кнопка «Выход» скрывается;
  - в меню снова отображается кнопка **«Вход»**.
- После выхода защищенные разделы требуют повторной авторизации.
