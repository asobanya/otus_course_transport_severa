# Требования и преднастройки: Карта и гео-слои

**1. Базовые элементы управления ГИС-картой (UI/UX)**
- При открытии главной страницы веб-портала по умолчанию загружается карта целевого региона. 
- На карте доступны элементы управления: контрол поиска по остановкам и маршрутам с кнопками меню, построить маршрут и кнопой  раскрытия/сворачивания Левой панели (ЛП), кнопки масштабирования «+» и «-», кнопка «Мое местоположение», чекбоксы "Для маломобильных", "Остановки", "Перекрытия", "Дороги". 
- Масштабирование и визуализация транспортных средств:
  - При уменьшении масштаба (отдалении) маркеры транспорта отображаются в виде **мелких цветных точек**. **Цвет маркера зависит от типа ТС** (автобус, троллейбус, маршрутное такси).
  - При увеличении масштаба (приближении) маркеры трансформируются в **крупные цветные маркеры** с иконкой типа ТС, плашкой номера маршрута и стрелкой - направлением движения ТС. .
- Кнопка **«Мое местоположение»** инициирует запрос браузера на предоставление прав геолокации и центрирует карту на текущих координатах пользователя.
 

**2. Нижняя панель переключения слоев и фильтрация**
- В нижней части экрана размещена панель с чекбоксами управления отображением слоев:
  - **«Остановки»**: при включении отображает маркеры остановочных пунктов на карте.
  - **«Перекрытия»**: при включении отображает слои временно перекрытых участков УДС, переданных из «Трансфлоу».
  - **«Дороги»**: при включении активирует отображение дорог разным цветом (классификация + объекты мероприятий из «Трансфлоу»).
  - **«Для маломобильных»**: фильтрует отображение ТС на карте, оставляя **только транспорт, адаптированный для маломобильных групп граждан**. ТС без признака доступности должны полностью скрываться с карты.
- При включении чекбокса **«Дороги»** в правой нижней части карты (над блоком зума +/-) появляется динамическая кнопка фильтрации дорог (пиктограмма дороги).
- Нажатие на кнопку фильтрации дорог открывает поп-ап окно настроек с перечнем типов дорог и мероприятий, позволяющим точечно включать/выключать их отображение чекбоксами.

**3. Тултипы и всплывающие подсказки при наведении (Hover)**
  - При наведении курсора на **остановку**, отображается тултип с названием, описанием и иконкой остановки.
  - При наведении курсора на уменьшенный маркер **ТС**, отображается тултип с номером маршрута, иконкой и цветом ТС.
  - Клик по маркеру **остановки или ТС** на карте центрирует область видимости на объекте и открывает соответствующую **карточку в ЛП**.
  - Наведение курсора мыши на **выделенный участок дороги** вызывает тултип с детальной информацией о проводимом мероприятии (Вид работ, Наименование объекта, Период) или о дороге (если по ней нет мероприятий).

### **4. Интеграция с административной системой «Трансфлоу» (E2E)**
- Введенное и опубликованное в системе «Трансфлоу» (раздел **УДР -> Мероприятия**) перекрытие с названием **«Тестовое_перекрытие_1»** должно корректно транслироваться на ГИС-карту портала «Транспорт Севера» при включенном слое **«Перекрытия»**.
