# Требования и преднастройки: Маршруты

**ТРЕБОВАНИЯ:**

**Открытие и состав Левой Панели (ЛП) раздела «Маршруты»**
* При клике в боковом меню по пункту **«Маршруты»** в ЛП открывается панель каталога маршрутов (URL: /#/routes).
* В шапке панели отображаются заголовок **«Маршруты»**, **кнопка «Закрыть» (крестик)** и строка поиска с плейсхолдером **«Поиск маршрута»**.
* Перечень маршрутов в ЛП **динамически фильтруется по текущей области видимости карты**: отображаются только те маршруты, траектория которых проходит через видимую область карты.
* Маршруты распределены по 3 основным блокам/категориям: **«Городские маршруты»**, **«Пригородные маршруты»** и **«Междугородние маршруты»**.
* Внутри категорий маршруты сгруппированы по **типу транспортного средства (ТС)** с соответствующей иконкой и цветными плашками (кирпичиками):
  * **Автобус** — зеленый цвет плашки;
  * **Троллейбус** — синий цвет плашки;
  * **Трамвай** — оранжевый цвет плашки.

**Поиск маршрутов**
* Поиск работает «на лету» по **номеру маршрута** (цифры, спецсимволы, например 18К) и по **текстовому названию** (конечные и промежуточные пункты).
* Результаты поиска ранжируются от наиболее релевантных к менее релевантным.
* Каждая строка поисковой выдачи содержит: иконку типа ТС, цветной кирпичик с номером и текстовое наименование маршрута.
* При вводе символов в поле поиска появляется **кнопка «Очистить» (крестик)**, возвращающая исходный вид с категориями.
* При отсутствии совпадений выводится сообщение **«Ничего не найдено»** (пустой список).

**Карточка детальной информации о маршруте**
* При выборе маршрута открывается детальная карточка маршрута (URL: /#/route/{id}?fwd=1), а **карта автоматически центрируется и масштабируется** так, чтобы весь трек маршрута полностью помещался на экране.
* Шапка карточки содержит: иконку типа ТС, кирпичик с номером, тип ТС словом («Автобус»/«Троллейбус»), **рейтинг** (число и звезда «5.0 ★», либо только звезда «★» при отсутствии оценок), кнопку **«Избранное»**.
* Ниже расположены навигационные вкладки: **«Маршрут»**, **«Расписание»** и **«Информация»**.
* Вкладка **«Информация»** отображает базовые сведения о маршруте (перевозчик, режим работы, контакты).
* При открытой карточке маршрута нижние чекбоксы управления слоями **«Для маломобильных»** и **«Остановки»** заблокированы для взаимодействия (**Disabled**).
**Вкладка «Маршрут», направления движения, аккордеон остановок и онлайн-трекинг ТС**
* В нижней части ЛП расположена кнопка переключения направления движения: **«Прямое направление»** (?fwd=1) / **«Обратное направление»** (?fwd=0).
* Переключение направления инвертирует список остановок в ЛП и меняет цвет трека на ГИС-карте:
  * **Прямое направление** — отображается **синий трек**;
  * **Обратное направление** — отображается **красный трек**.
* В списке остановок промежуточная часть длинных маршрутов скрыта под кнопкой **«Показать еще N»**:
* Клик по кнопке раскрывает все скрытые промежуточные остановки;
* Повторный клик сворачивает список обратно.
* Если на линии есть **активные ТС**: на карте отображаются их маркеры, а в ЛП остановки подсвечиваются цветом и выводят зеленый индикатор с **прогнозируемым временем прибытия**.
* Если на линии **нет активных ТС**: маркеры транспорта на карте отсутствуют, все остановки в списке ЛП отображаются **серым цветом** без времени прибытия.

**Вкладка «Расписание» и интеграция с «Трансфлоу»**
* Данные вкладки синхронизируются из системы «Трансфлоу»:
* При **интервальном режиме**: выводится текстовый блок вида **«с 04:00 по 03:00 каждые X - Y мин»**;
* При **фиксированном расписании**: выводится расписание в виде **кирпичиков времени для каждой остановки** (отображаются только те остановки, для которых в «Трансфлоу» явно задано время рейсов);
* Если для маршрута в «Трансфлоу» **не заведен режим работы**: вкладка **«Расписание» полностью скрывается из ЛП**.

**Построение маршрута между точками (ЛП «Построить маршрут»)**
* У поисковой строки размещена кнопка **«Построить маршрут»**, клик по которой открывает отдельную панель с полями ввода **«Откуда»** (точка А), **«Куда»** (точка Б) и кнопкой **«Реверс»** (смена мест А и Б).
* Внутри каждого поля ввода («Откуда» / «Куда») отображается **кнопка «Очистить» (крестик)** для точечного сброса выбранной остановки.
* В нижней части панели выводится блок **«Ближайшие остановочные пункты»** (до 5 ближайших остановок, попадающих в текущую область карты).
* При разрешенной геолокации в браузере рядом с названиями ближайших остановок выводится **расстояние до них в метрах/километрах**.
* Заполнение полей «Откуда» и «Куда» возможно:
  * Непосредственным **кликом по маркеру остановки на карте**;
  * Вводом текста с выбором подходящей остановки из выпадающего списка подсказок под инпутом.
* После указания обеих точек:
  * В ЛП формируется перечень **вариантов проезда** (прямые и с пересадками);
  * На карте отрисовываются **маркеры «Откуда» и «Куда»** (флажки А и Б), а также **цветные треки каждого предложенного варианта**;
  * В строке каждого варианта в ЛП отображаются: **количество пересадок**, **суммарное время в пути**, цепочка маршрутов с иконками ТС и цветными кирпичиками номеров.
* **Наведение курсора мыши на трек варианта на карте**: отображает всплывающий тултип с параметрами **«От - До»**, общим временем в пути и количеством пересадок.
* **Выбор конкретного варианта маршрута (клик в ЛП или по треку на карте)**:
* На карте подсвечивается выбранная траектория, отображаются **маркеры промежуточных остановок** и **уменьшенные маркеры пересадок**;
* В ЛП открывается детальный пошаговый маршрут: общее время в пути, сегменты поездки с временем на каждом маршруте, список проезжаемых остановок и время пеших переходов/пересадок;
* В шапке детального маршрута доступен **крестик возврата**, по нажатию на который происходит возврат к общему списку предложенных вариантов.
