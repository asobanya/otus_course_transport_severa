# Требования и преднастройки: Меню

**Назначение раздела**
Боковое меню предназначено для:
- навигации по основным разделам портала «Транспорт Севера»;
- отображения действий, доступных пользователю в зависимости от состояния авторизации.

**Открытие и закрытие меню**
- Боковое меню открывается по кнопке **«Меню»**.
- В открытом меню отображаются:
  - логотип портала;
  - кнопка закрытия.
- Меню закрывается:
  - по нажатию на **крестик**;
  - по **клику по свободной области вне меню**.
- После закрытия меню пользователь остается в текущем разделе портала.

**Состав меню**
- В боковом меню доступны пункты:
  - «Маршруты»;
  - «Остановки»;
  - «Избранное»;
  - «Новости»;
  - «Опросы»;
  - «Справка»;
  - «Гид по порталу».
- Пункты **«Маршруты», «Остановки», «Новости», «Справка» и «Гид по порталу» доступны независимо от состояния авторизации пользователя**.

**Навигация по публичным разделам**
- Публичные пункты меню открывают соответствующие разделы:
  - «Маршруты» -> /#/routes;
  - «Остановки» -> /#/stops;
  - «Новости» -> /#/news;
  - «Справка» -> /#/info;
  - «Гид по порталу» -> /#/guide.
- После выбора публичного раздела **боковое меню закрывается**.

**Доступ неавторизованного пользователя**
- Для неавторизованного пользователя:
  - отображается кнопка **«Вход»**;
  - кнопка «Выход» отсутствует;
  - данные профиля отсутствуют.
- Нажатие кнопки «Вход» открывает форму авторизации.
- Разделы **«Избранное» и «Опросы» требуют авторизации**.
- При попытке неавторизованного пользователя открыть «Избранное» или «Опросы»:
  - защищенный раздел не открывается;
  - пользователь перенаправляется на форму авторизации;
  - URL соответствует /#/login.

**Состояние авторизованного пользователя**
- Для авторизованного пользователя:
  - отображаются **данные профиля**;
  - отображается кнопка **«Выход»**;
  - кнопка «Вход» отсутствует.
- Авторизованному пользователю доступны разделы «Избранное» и «Опросы».
- Защищенные пункты меню открывают соответствующие разделы:
  - «Избранное» -> /#/favorites;
  - «Опросы» -> /#/polls.
- После перехода в «Избранное» или «Опросы» **боковое меню закрывается**.
