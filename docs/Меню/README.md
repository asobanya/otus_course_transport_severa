# Требования и преднастройки: Меню

**ТРЕБОВАНИЯ**

**Назначение раздела**
Боковое меню предназначено для навигации по основным разделам портала «Транспорт Севера» и отображения действий, доступных пользователю в зависимости от состояния авторизации.

**Открытие и закрытие меню**
Боковое меню открывается по кнопке **«Меню»**.
В открытом меню отображаются логотип портала и кнопка закрытия.
Меню закрывается при нажатии на **крестик** или при **клике по свободной области вне меню**.
При закрытии меню пользователь остается в текущем разделе портала.

**Состав меню**
В боковом меню доступны пункты «Маршруты», «Остановки», «Избранное», «Новости», «Опросы», «Справка» и «Гид по порталу».
Пункты **«Маршруты», «Остановки», «Новости», «Справка» и «Гид по порталу» доступны независимо от состояния авторизации пользователя**.

**Навигация по публичным разделам**
Пункт «Маршруты» открывает раздел с URL /#/routes.
Пункт «Остановки» открывает раздел с URL /#/stops.
Пункт «Новости» открывает раздел с URL /#/news.
Пункт «Справка» открывает раздел с URL /#/info.
Пункт «Гид по порталу» открывает раздел с URL /#/guide.
После выбора пункта публичного раздела **боковое меню закрывается**.

**Доступ неавторизованного пользователя**
Для неавторизованного пользователя в меню отображается кнопка **«Вход»**, а кнопка «Выход» и данные профиля отсутствуют.
Нажатие кнопки «Вход» открывает форму авторизации.
Разделы **«Избранное» и «Опросы» требуют авторизации**.
При попытке неавторизованного пользователя открыть «Избранное» или «Опросы» пользователь перенаправляется на форму авторизации с URL /#/login.

**Состояние авторизованного пользователя**
Для авторизованного пользователя в меню отображаются **данные профиля и кнопка «Выход»**, а кнопка «Вход» отсутствует.
Авторизованному пользователю доступны разделы «Избранное» и «Опросы».
Пункт «Избранное» открывает раздел с URL /#/favorites.
Пункт «Опросы» открывает раздел с URL /#/polls.
После перехода в «Избранное» или «Опросы» **боковое меню закрывается**.
