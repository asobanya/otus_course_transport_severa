# TESTY-1156: 1. Меню: Открытие, состав и закрытие меню гостя

## Описание
Проверка открытия бокового меню, состава доступных пунктов, состояния элементов авторизации и закрытия меню по крестику.

## Сценарий
### Шаг 1
* **Действие:** Нажать кнопку «Меню»
* **Ожидаемый результат:** Открывается боковое меню портала.

### Шаг 2
* **Действие:** Проверить основные элементы меню
* **Ожидаемый результат:** Отображаются логотип портала и крестик закрытия меню.

### Шаг 3
* **Действие:** Проверить состав навигации
* **Ожидаемый результат:** Отображаются пункты «Маршруты», «Остановки», «Избранное», «Новости», «Опросы», «Справка» и «Гид по порталу».

### Шаг 4
* **Действие:** Проверить область авторизации
* **Ожидаемый результат:** Отображается кнопка «Вход»; кнопка «Выход» и данные профиля отсутствуют.

### Шаг 5
* **Действие:** Нажать на крестик
* **Ожидаемый результат:** Боковое меню полностью скрывается; пользователь остается в текущем разделе.

## Итоговый ожидаемый результат
Боковое меню корректно открывается, содержит предусмотренные элементы для неавторизованного пользователя и закрывается по крестику.

# TESTY-1157: 2. Навигация: Переход в публичные разделы

## Описание
Проверка переходов из бокового меню в разделы, доступные независимо от состояния авторизации.

## Сценарий
### Шаг 1
* **Действие:** Открыть меню и выбрать «Маршруты»
* **Ожидаемый результат:** Открывается раздел «Маршруты», URL соответствует /#/routes; боковое меню закрывается.

### Шаг 2
* **Действие:** Открыть меню и выбрать «Остановки»
* **Ожидаемый результат:** Открывается раздел «Остановки», URL соответствует /#/stops; боковое меню закрывается.

### Шаг 3
* **Действие:** Открыть меню и выбрать «Новости»
* **Ожидаемый результат:** Открывается раздел «Новости», URL соответствует /#/news; боковое меню закрывается.

### Шаг 4
* **Действие:** Открыть меню и выбрать «Справка»
* **Ожидаемый результат:** Открывается раздел «Справка», URL соответствует /#/info; боковое меню закрывается.

### Шаг 5
* **Действие:** Открыть меню и выбрать «Гид по порталу»
* **Ожидаемый результат:** Открывается раздел «Гид по порталу», URL соответствует /#/guide; боковое меню закрывается.

## Итоговый ожидаемый результат
Все публичные пункты меню открывают соответствующие разделы; после перехода боковое меню закрывается.

# TESTY-1158: 3. Права: Доступ гостя к «Избранному» и «Опросам»

## Описание
Проверка ограничения доступа неавторизованного пользователя к разделам «Избранное» и «Опросы».

## Сценарий
### Шаг 1
* **Действие:** Открыть меню и выбрать «Избранное»
* **Ожидаемый результат:** Раздел «Избранное» не открывается; пользователь перенаправляется на форму авторизации, URL соответствует /#/login.

### Шаг 2
* **Действие:** Вернуться на главную страницу, открыть меню и выбрать «Опросы»
* **Ожидаемый результат:** Раздел «Опросы» не открывается; пользователь перенаправляется на форму авторизации, URL соответствует /#/login.

## Итоговый ожидаемый результат
Гостю недоступны «Избранное» и «Опросы»; при попытке перехода открывается форма авторизации.
