# Требования и преднастройки: Справка и гид по порталу

**ТРЕБОВАНИЯ:**


**Открытие и состав панели Справки**
При переходе в раздел **Справка** открывается боковая панель. Панель содержит заголовок **Справка**, статичный текстовый блок с информацией о портале, копирайт **® 2026 Транспорт Севера** и кнопку закрытия (крестик). В тексте обязательно присутствует кликабельная ссылка на сайт **Трансфлоу** (http://transflow.ru).

**Закрытие панели Справки**
При нажатии на крестик панель Справки полностью скрывается со страницы, а кнопка раскрытия Левой Панели (ЛП) теряет класс **active**.

**Открытие и состав панели Гида**
При переходе в раздел **Гид по порталу** открывается боковая панель. Доступны заголовок **Гид портала Транспорт Севера**, кнопки навигации (Вперед/Назад), кнопка **Подробнее**, счетчик слайдов и кнопка закрытия (крестик). По умолчанию активен первый слайд из 9 существующих.

**Функционал слайдера и состояний кнопок**
Слайдер состоит из **9 слайдов**. При нажатии кнопки **Вперед** происходит переключение на следующий слайд с заменой текста и обновлением счетчика. На первом слайде кнопка **Назад** имеет класс **disabled**. На последнем (9-м) слайде кнопка **Вперед** приобретает класс **disabled**. Одновременно отображается только один активный слайд.

**Переход в раздел FAQ**
При нажатии кнопки **Подробнее** слайдер скрывается, отображается навигационный список из **8 вопросов**.

**Навигация и контент ответов FAQ**
При клике на вопрос в правой части экрана открывается соответствующий блок с ответом. У выбранного вопроса появляется класс **active**. При выборе другого вопроса класс **active** переходит на него, а контент в правой области обновляется, отображая заголовок, текстовые подпункты и изображения.

**Закрытие панели Гида**
Первое нажатие на крестик при открытом слайдере переводит панель в режим FAQ. Второе нажатие на крестик полностью скрывает панель Гида со страницы.
