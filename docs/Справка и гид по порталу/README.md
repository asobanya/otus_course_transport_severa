# Требования и преднастройки: Справка и гид по порталу

**Назначение разделов**
Разделы «Справка» и «Гид по порталу» предназначены для ознакомления пользователя с возможностями портала «Транспорт Севера» и получения справочной информации.
- «Справка» содержит общую информацию о портале и ссылку на сайт Трансфлоу.
- «Гид по порталу» содержит:
  - пошаговый слайдер с основными возможностями портала;
  - раздел FAQ с вопросами и подробными ответами.

**Открытие и состав панели «Справка»**
- При переходе в раздел «Справка» открывается боковая панель.
- В панели отображаются:
  - заголовок **«Справка»**;
  - статичный текст с информацией о портале;
  - копирайт **«® 2026 Транспорт Севера»**;
  - кликабельная ссылка на сайт Трансфлоу;
  - крестик закрытия панели.

**Закрытие панели «Справка»**
- При нажатии на крестик:
  - панель **полностью скрывается**;
  - пользователь остается на текущей странице портала;
  - кнопка раскрытия Левой Панели возвращается в неактивное состояние.

**Открытие и состав панели «Гид по порталу»**
- При переходе в раздел «Гид по порталу» открывается боковая панель.
- В режиме слайдера отображаются:
  - заголовок **«Гид портала Транспорт Севера»**;
  - кнопка «Назад»;
  - кнопка «Вперед»;
  - кнопка **«Подробнее»**;
  - счетчик слайдов;
  - крестик закрытия.
- Слайдер содержит **9 слайдов**.
- При первоначальном открытии:
  - отображается первый слайд;
  - счетчик имеет значение **1 / 9**;
  - одновременно отображается **только один слайд**;
  - кнопка «Назад» недоступна.

**Навигация по слайдам**
- Кнопка «Вперед» переключает пользователя на следующий слайд.
- Кнопка «Назад» переключает пользователя на предыдущий слайд.
- При переключении:
  - содержимое активного слайда обновляется;
  - счетчик соответствует номеру текущего слайда;
  - одновременно отображается **только один слайд**.
- На первом слайде кнопка **«Назад» недоступна**.
- На девятом слайде кнопка **«Вперед» недоступна**.
- Счетчик последнего слайда имеет значение **9 / 9**.

**Переход в FAQ**
- При нажатии кнопки **«Подробнее»**:
  - режим слайдера скрывается;
  - отображается навигационный список FAQ.
- Список FAQ содержит **8 вопросов**.

**Навигация и ответы FAQ**
- При выборе вопроса:
  - выбранный вопрос визуально выделяется;
  - в области ответа отображается соответствующий контент.
- Ответ содержит:
  - заголовок;
  - текстовую информацию;
  - предусмотренные для ответа изображения.
- При выборе другого вопроса:
  - выделение переходит на новый вопрос;
  - предыдущий вопрос перестает быть выбранным;
  - содержимое области ответа обновляется.

**Закрытие панели «Гид по порталу»**
- Закрытие панели выполняется **в два этапа**:
  - первое нажатие на крестик в режиме слайдера переводит панель в режим FAQ;
  - второе нажатие на крестик в режиме FAQ полностью закрывает панель.
