# TESTY-1168: 1. Гид: Открытие и состав слайдера

## Описание
Проверка первоначального состояния панели «Гид по порталу», состава элементов управления и первого слайда.

## Сценарий
### Шаг 1
* **Действие:** Перейти в раздел «Гид по порталу»
* **Ожидаемый результат:** Открывается боковая панель с заголовком «Гид портала Транспорт Севера».

### Шаг 2
* **Действие:** Проверить элементы управления
* **Ожидаемый результат:** Отображаются кнопки «Назад», «Вперед», «Подробнее», крестик закрытия и счетчик слайдов.

### Шаг 3
* **Действие:** Проверить первоначальное состояние слайдера
* **Ожидаемый результат:** Отображается первый слайд; счетчик имеет значение 1 / 9; одновременно виден только один слайд.

### Шаг 4
* **Действие:** Проверить кнопки навигации
* **Ожидаемый результат:** Кнопка «Назад» недоступна; кнопка «Вперед» доступна.

## Итоговый ожидаемый результат
Гид открывается в режиме первого слайда с корректным набором элементов управления и начальными состояниями навигации.

# TESTY-1169: 2. Гид: Навигация по слайдам и граничные состояния

## Описание
Проверка последовательного переключения слайдов вперед и назад, изменения счетчика и блокировки навигации на первом и последнем слайдах.

## Сценарий
### Шаг 1
* **Действие:** Нажать кнопку «Вперед»
* **Ожидаемый результат:** Открывается второй слайд; счетчик изменяется на 2 / 9; одновременно отображается только один слайд.

### Шаг 2
* **Действие:** Нажать кнопку «Назад»
* **Ожидаемый результат:** Снова открывается первый слайд; счетчик изменяется на 1 / 9; кнопка «Назад» становится недоступна.

### Шаг 3
* **Действие:** Последовательно нажимать кнопку «Вперед» до девятого слайда
* **Ожидаемый результат:** Слайды переключаются по порядку; после каждого переключения отображается только один слайд, а счетчик увеличивается в соответствии с его номером.

### Шаг 4
* **Действие:** Проверить состояние девятого слайда
* **Ожидаемый результат:** Счетчик имеет значение 9 / 9; кнопка «Вперед» недоступна; кнопка «Назад» доступна.

### Шаг 5
* **Действие:** Нажать кнопку «Назад»
* **Ожидаемый результат:** Открывается восьмой слайд; счетчик изменяется на 8 / 9; кнопка «Вперед» снова становится доступна.

## Итоговый ожидаемый результат
Навигация вперед и назад работает корректно, счетчик соответствует активному слайду, а граничные кнопки становятся недоступны только на первом и последнем слайдах.

# TESTY-1170: 3. FAQ: Переход из слайдера к списку вопросов

## Описание
Проверка перехода из режима слайдера в FAQ по кнопке «Подробнее».

## Сценарий
### Шаг 1
* **Действие:** Перейти в раздел «Гид по порталу» и нажать кнопку «Подробнее»
* **Ожидаемый результат:** Режим слайдера скрывается, открывается навигация FAQ.

### Шаг 2
* **Действие:** Проверить список вопросов
* **Ожидаемый результат:** В FAQ отображаются ровно 8 вопросов.

### Шаг 3
* **Действие:** Проверить состояние слайдера
* **Ожидаемый результат:** Слайды, счетчик и кнопки навигации слайдера больше не отображаются.

## Итоговый ожидаемый результат
Кнопка «Подробнее» переводит Гид из режима слайдера в FAQ со списком из 8 вопросов.

# TESTY-1171: 4. FAQ: Навигация по вопросам и отображение ответов

## Описание
Проверка выбора вопросов FAQ, отображения соответствующих ответов и переключения выделения между вопросами.

## Сценарий
### Шаг 1
* **Действие:** Открыть FAQ и выбрать первый вопрос
* **Ожидаемый результат:** Первый вопрос визуально выделяется; отображается соответствующий блок ответа.

### Шаг 2
* **Действие:** Проверить содержимое первого ответа
* **Ожидаемый результат:** Отображаются заголовок, текстовая информация и предусмотренное изображение.

### Шаг 3
* **Действие:** Выбрать второй вопрос
* **Ожидаемый результат:** Второй вопрос становится выделенным; первый вопрос перестает быть выделенным; содержимое области ответа обновляется.

### Шаг 4
* **Действие:** Проверить содержимое второго ответа
* **Ожидаемый результат:** Отображается ответ, соответствующий второму выбранному вопросу, с заголовком, текстовой информацией и предусмотренным контентом.

## Итоговый ожидаемый результат
Выбор вопроса открывает соответствующий ответ, а состояние выбранного вопроса и содержимое области ответа корректно обновляются.

# TESTY-1174: 7. Справка: Закрытие панели

## Описание
Проверка закрытия панели «Справка» и возврата управления Левой Панелью в исходное состояние.

## Сценарий
### Шаг 1
* **Действие:** Перейти в раздел «Справка»
* **Ожидаемый результат:** Панель «Справка» открывается; кнопка управления Левой Панелью находится в активном состоянии.

### Шаг 2
* **Действие:** Нажать на крестик в панели «Справка»
* **Ожидаемый результат:** Панель полностью скрывается; пользователь остается на текущей странице портала.

### Шаг 3
* **Действие:** Проверить состояние кнопки управления Левой Панелью
* **Ожидаемый результат:** Кнопка находится в неактивном состоянии.

## Итоговый ожидаемый результат
Панель «Справка» полностью закрывается, а кнопка управления Левой Панелью возвращается в неактивное состояние.
